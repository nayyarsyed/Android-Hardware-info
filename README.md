# Android Hardware Info - 8-BIT Retro Version

A modern Android application built with **Jetpack Compose** that displays detailed hardware information about your device in a nostalgic **8-bit retro style**.


<img width="577" height="1065" alt="image" src="https://github.com/user-attachments/assets/036d7e9c-1cd1-4b10-b011-4eec1ed5d6b1" />


## ✨ Features

- **Dashboard** with retro-styled navigation cards
- **Device Information** (model, manufacturer, Android version, etc.)
- **CPU Details** (cores, architecture, frequencies)
- **Battery Status** (level, health, temperature, charging status)
- **Sensors** (accelerometer, gyroscope, proximity, etc.)
- **Camera Information** (rear/front cameras, resolutions, capabilities)
- **GPS / Location** hardware details

## 🛠 Tech Stack

- **Language**: Kotlin 100%
- **UI**: Jetpack Compose
- **Architecture**: Single Activity with Navigation Compose
- **Min SDK**: 34 (Android 14)
- **Target SDK**: 35
- **Camera**: CameraX
- **Coroutines** for async operations
